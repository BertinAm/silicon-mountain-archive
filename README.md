# Silicon Mountain Archive 🏔️

An open-source, living archive documenting the founders, builders, and history of **Silicon Mountain** — Cameroon's premier technology ecosystem, centred in Buea, Southwest Region.

This project exists to preserve and expand the public record of one of Africa's most resilient innovation communities — from its origins in cyber cafes in 2006 to a movement now reaching Liberia in 2025.

## 📖 What's Inside

The archive currently profiles **25+ key figures** across four generations of Silicon Mountain's history:

| Chapter | Period | Focus |
|--------|--------|-------|
| I — The Founding Generation | 2006–2010 | PassGCE, AfroVisioN, ActivSpaces |
| II — The GDG Wave | 2011–2016 | GDG Buea, Feem, Wikimedia, ICT4KIDS |
| III — The MountainHub Generation | 2018–Present | MountainHub, CITSCM, Nervtek |
| IV — The Supporting Cast | All eras | Community builders, connectors |

Each profile documents:
- Full background and education
- Career trajectory
- Current companies and roles
- Social media handles and digital footprints
- Direct quotes from interviews and public statements

## 🤝 How to Contribute

This is a **community-maintained archive**. We welcome pull requests from anyone with knowledge of the Silicon Mountain ecosystem — whether you're a founder, a researcher, a journalist, or someone who was just there.

### Ways to contribute

- **Add a missing profile** — there are hundreds of builders not yet documented
- **Update an existing profile** — current roles, new companies, awards
- **Fix inaccuracies** — something is wrong? Open a PR with a source
- **Add sources** — strengthen existing claims with links to articles, interviews, or documentation
- **Improve the design** — the site is a single HTML file, easy to edit

### Contribution guidelines

1. **Fork** this repository
2. **Edit** `index.html` with your additions
3. **Source everything** — every claim should be traceable to a public source (LinkedIn, news article, personal site, etc.)
4. **Open a Pull Request** with a short description of what you added and why
5. If you are the person being profiled, you are welcome to submit your own PR — just note it in the PR description

### Adding a new profile

When adding a new person, please include at a minimum:
- Full name and known aliases
- Role(s) in the Silicon Mountain ecosystem
- Current company/role (with source)
- At least one social handle or public link
- A brief description of their contribution

You don't need to have everything — a partial profile is better than no profile. Others can fill in the gaps.

### What not to submit

- Unverifiable claims without a source
- Promotional or marketing content
- Content that the person has explicitly asked not to be published
